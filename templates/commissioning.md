## Test ledger

| ID | Hypothesis / requirement | Setup and input | Expected result | Observed result / artifact | Evidence type | Decision |
|---|---|---|---|---|---|---|
| | | | | | planned / simulated / measured / user-reported | pass / fail / not tested / inconclusive |

Include normal ranges, unavailable values, stale data, reboot, two same-type sensors,
address changes, missing fragments, duplicate bridges and any authorized controls.
For each failure record a next discriminating test; stop after three non-converging
passes. Keep independent physical measurements separate from decoded values.
